What is the project about?

This project is about using a digitial grocery list where you can add, view, remove or erase the list/to the list, etc.

How to use it / set it up?

Run it in a python script

What are the features of the project?

It uses menu options so the user can choose whatever they want to do(add, view, remove, clear), uses a clean exit method, saves grocery list data by using JSON, checks if data exists in the grocery list before doing specific operations, and does a lot more realistic features like checking budget or marking items as bought, etc.
